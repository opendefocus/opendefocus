# <i class="fa-solid fa-arrows-to-eye"></i> Focal plane
The **Focal Plane** parameter (Defocus tab) sets the depth that stays in focus. Depths in front of it fall in the near field, and depths behind it in the far field.

The **Protect** parameter sets the width of an in-focus band around the focal plane. The default is 0.

!!! note "Only for depth and camera based"
    In 2D mode the defocus is set by **Size** alone, so the focal plane has no effect.

---

## Setting the focal plane
Set **Focal Plane** to the depth you want in focus. With Use Camera on, it must be a positive distance in the **World Unit**. The plugin has no focal plane preview, so the output always shows the defocus.
