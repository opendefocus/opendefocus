# <i class="fa-solid fa-rocket"></i> Quickstart

This is a quick reference guide to getting started defocusing with the OpenDefocus OpenFX plugin. It links to more detailed descriptions, but this should get you far enough to make some pretty images!

Each parameter has a hint, shown as a tooltip in the host. If you ever need some information, just hover over the parameter.

If you're looking for explanations, the [<i class="fa-solid fa-magnifying-glass"></i> Detailed](../detailed/index.md) page contains that. If you're searching something but don't know where to find it? The search bar can probably find it for you.

The parameters are grouped in four tabs: **Defocus**, **Camera**, **Bokeh** and **Non-Uniform**. We'll go through them in that order.
